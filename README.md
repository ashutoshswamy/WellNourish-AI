# WellNourish AI

![WellNourish AI](./public/og-image.jpg)

A premium, AI-driven meal planning application designed to revolutionize your approach to nutrition. Built with a focus on personalization, aesthetics, and ease of use, it helps you reach your health goals with customized meal plans, interactive shopping lists, and a seamless dashboard experience.

## Features

- AI-powered nutrition — personalized meal plans via Google's Gemini Pro, tailored to dietary preferences, health goals, and metrics
- Dynamic dashboard to track progress and manage daily meals
- Interactive shopping lists automatically generated from meal plans
- In-depth profiling — comprehensive onboarding capturing biometrics, activity levels, and dietary restrictions
- Secure authentication — email/password and Google sign-in via Firebase Auth
- Real-time, persistent data storage using Firestore
- Fully responsive, mobile-first design
- Premium UI/UX with Framer Motion and GSAP animations
